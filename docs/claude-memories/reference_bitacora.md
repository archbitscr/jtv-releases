La bitácora de mejoras y modificaciones del proyecto se encuentra en `docs/BITACORAS_DE_MEJORAS.md`.

**How to apply:** Al completar una tarea (después del build exitoso y commit), agregar una entrada en la bitácora documentando todas las correcciones y modificaciones realizadas para lograrla. Seguir el formato existente: fecha, título, problema, modificaciones con rutas de archivos.
